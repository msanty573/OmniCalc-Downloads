OmniCalc package repositories

dnf (RHEL, AlmaLinux, Rocky, Fedora)

  • OmniCalc 3.18.2 (el10, 64-bit ARM)
  • OmniCalc 3.18.2 (el10, 64-bit Intel/AMD)

Add the repository once, then OmniCalc updates with the rest of the system:

sudo rpm --import https://msanty573.github.io/OmniCalc-Downloads/RPM-GPG-KEY-omnicalc
sudo curl -o /etc/yum.repos.d/omnicalc.repo https://msanty573.github.io/OmniCalc-Downloads/omnicalc.repo
sudo dnf install omnicalc

apt (Ubuntu 26.04 and newer)

  • OmniCalc 3.18.2 (64-bit Intel/AMD)
  • OmniCalc 3.18.2 (64-bit ARM)

Installing the package also adds this repository, so OmniCalc then updates with the rest of the system:

wget https://github.com/msanty573/OmniCalc-Downloads/releases/download/latest/omnicalc.ubuntu.$(dpkg --print-architecture).deb
sudo apt install ./omnicalc.ubuntu.*.deb
